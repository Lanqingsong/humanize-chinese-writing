# 中文自然表达模式参考

本参考用于定位模板化表达并选择改写方法。单一词语不构成 AI 证据；结合上下文、密度和语域判断。

## 0. 回答者惯性与作者站位

### 0.1 可观察表现

有些文本语法通顺、信息也完整，仍然像聊天答复。常见表现包括：

- 开头先确认对方：“你说得对”“这个问题很重要”“确实如此”；
- 正文不断指向提问者：“你可能会问”“关于这一点”“这里需要说明”；
- 先虚构一个误解，再予以纠正：“很多人以为 X，其实是 Y”；
- 每段都在补充完整性：“此外”“还需要注意”“不能忽略”；
- 结尾回到服务姿态：“希望有所帮助”“如果需要还可以继续”；
- 段落顺序沿着提示词展开，缺少作品自身的组织原则。

这些表现合在一起，会让文章像对一个隐形用户逐项作答。单独出现一句不必修改，连续出现时需要重建站位。

### 0.2 用户纠正如何进入正文

用户常用“不是 X，是 Y”纠正偏差。这句话属于对话现场，正文需要吸收的是 `Y` 代表的要求。

例：用户说“这不是正式总结，我想写得轻松一些”。

不要写：

> 这不是正式总结，而是一段轻松的分享。

可直接写：

> 我想从最近遇到的一件小事说起。

改写步骤：

1. 提取要求：语气轻松，内容属于分享；
2. 提取排除项：删去公文式概括和正式总结；
3. 选择结构：事情发生 → 观察变化 → 留下感受；
4. 从目标内容起笔，不复述纠正过程。

### 0.3 从答题结构转为作品结构

答题结构追求逐项回应；作品结构追求材料之间的内在推进。可按文本任务选择：

- 说明：现象 → 原因 → 关系 → 条件 → 后果；
- 教程：目标 → 操作 → 观察 → 判断 → 常见问题；
- 分析：问题 → 材料 → 推理 → 结论；
- 介绍：对象 → 读者 → 内容边界 → 使用路径；
- 叙事：视角 → 场景变化 → 冲突 → 余波。

用户提示提供材料和约束，不必决定文章段落顺序。

### 0.4 创作思维的最低要求

创作不等于增加修辞。至少完成四个主动选择：

1. 选择叙述焦点：这一段只解决什么；
2. 分配叙事权重：哪些内容略写，哪些需要放慢；
3. 安排材料顺序：读者需要先知道什么，后面的判断才成立；
4. 决定结束位置：信息完成后停止，不追加服务式总结。

### 0.5 编辑检查

删去用户问题、聊天历史和标题后检查：

- 文章能否独立成立；
- 是否仍有句子在确认、纠正、安抚或邀请提问者；
- 每段是否由主题推进，而非由“还要回答什么”推进；
- 对立句是否在传递必要辨析，还是保留了争辩语气；
- 是否有明确的详略和叙述焦点。

## 1. 结构层模式

### 1.1 空泛开场

高风险：

> 在当今快速变化的时代背景下，时间管理正发挥着越来越重要的作用。

问题在于主题出现太晚，且“快速发展”“越来越重要”没有提供可核验信息。

改为：

> 租房时需要同时考虑预算、通勤时间、采光和合同条款。

从对象、矛盾、使用场景或结论起笔。

### 1.2 标题复述

高风险：

> ## 本书的特点
>
> 本书具有以下几个特点。

删除第二句，直接写具体特点。标题已经完成提示任务，正文要增加信息。

### 1.3 固定三段式

连续章节都使用“首先、其次、最后”，或每节固定三点，会产生提纲拼接感。

处理方法：

- 真实流程按时间或因果顺序保留；
- 并列项数量由内容决定，不强求三项；
- 有主次关系时先写主要判断，再补限制；
- 短内容用自然段，不必强行列点。

### 1.4 段尾反复拔高

高风险段尾：

- 这体现了系统性思维的重要性。
- 这也是项目成功的关键所在。
- 归根结底，真正重要的是回到用户价值。

优先改成具体结果、边界条件或下一步动作。整篇保留一处总括性收束即可。

### 1.5 段落等长与句法复刻

连续多个段落字数接近、都以“在……方面”开头、都以“因此……”收尾，会显得经过模板填充。

先确认每段任务：定义、解释、举例、比较、限制或结论。任务不同，长度和句法自然会不同。

## 2. 信息层模式

### 2.1 抽象评价代替事实

高风险：

> 该方案具有强大的综合能力，能够全面提升项目质量。

改为：

> 该方案同时记录检出率、误检率、节拍和异常恢复时间，便于在验收阶段定位瓶颈。

用对象、动作、条件、参数和结果替代“强大、全面、重要、有效”。

### 2.2 同义词堆叠

高风险：

> 进行全面、深入、系统、细致的分析与探讨。

改为：

> 分析分辨率、帧率和接口约束。

多个抽象形容词连用时，通常缺少分析对象。

### 2.3 同义复述

标题复述一次、正文解释一次、段尾再总结一次，会稀释信息。

处理方法：保留信息量最高的一句；其余位置补例子、条件或后果。补不出新信息时直接删除。

### 2.4 宣传与价值膨胀

谨慎使用：赋能、助力、深度融合、全方位、多维度、生态闭环、里程碑、至关重要、不可或缺、全面升级。

这些词不是绝对禁用，但需要回答“具体改变了什么”。回答不出来时改成动作和结果。

### 2.5 模糊归因

“研究表明”“专家认为”“业内普遍认为”需要来源。没有来源时可写明观察范围，或改成可验证事实。

## 3. 句式层模式

### 3.1 “不是 X，而是 Y”及其变体

常见变体：

- 不是 X，而是 Y
- 并不是 X，而是 Y
- 关键不在于 X，而在于 Y
- 真正重要的不是 X，而是 Y
- 与其说 X，不如说 Y
- X 不等于 Y
- X 并非 Y
- 这并不意味着 X
- 不能只看 X，还要看 Y

这组句式适合纠正常见误解。连续出现时，文本会一直以反驳姿态推进，像在预设一个并不存在的错误读者。

四种改法：

1. `直陈结论`

   原句：关键不在于像素有多高，而在于系统是否满足缺陷分辨要求。

   改写：相机像素数需要满足缺陷分辨要求，并与视野和镜头分辨能力匹配。

2. `拆成条件`

   原句：焦距变长不等于精度一定提高。

   改写：焦距变长会放大像面位移，同时缩小视场；最终精度还受镜头分辨率、采样和标定误差影响。

3. `说明关系`

   原句：立体校正不是美化图像，而是降低匹配难度。

   改写：立体校正把对应点整理到同一行，从而缩小匹配搜索范围。

4. `保留必要辨析`

   原句：个人判断不等于事实，判断需要证据支持。

   当读者确实容易混淆两个术语时可以保留，但同一小节不要连续使用多个对立句。

### 3.2 元话语

高风险：下面让我们深入探讨、接下来将从三个方面展开、希望以上内容有所帮助。

正文直接进入对象。流程导航只在长文确实需要时保留，并写明读者将获得的具体信息。

### 3.3 伪深刻判断

高风险：真正决定项目成败的是系统性思维。

改为：项目验收前需要验证检出率、误检率、节拍、通信和异常恢复。

“真正、核心、本质、关键”后面若仍是抽象名词，继续追问可观察的动作或结果。

### 3.4 连续定义句

连续使用“A 是……”“B 是……”“C 是……”会像词典拼接。保留首次定义，后续用关系、例子或作用推进。

### 3.5 虚化动词

高风险：实现赋能、助力构建、推动形成、进行分析、开展探讨。

优先使用：是、由、有、包含、需要、采用、导致、限制、决定、取决于。

### 3.6 对冲词密集

通常、往往、一般、可能、相对、一定程度上连续出现会削弱判断。

能给条件时给条件：

> 在曝光时间小于运动模糊上限时，延长曝光可提高信噪比。

无法确认时保留必要限定，不把审慎表达全部改成绝对结论。

## 4. 节奏与标点模式

### 4.1 连续短句

高风险：

> 先看图。再看参数。最后看结果。这个很重要。

短句适合强调。连续使用会像自动生成的提纲。把同一逻辑链合成一句，重点处再落短句。

### 4.2 句首重复

连续三句以“通过”“对于”“在……方面”“这意味着”开头，优先改其中两句。不要为了变化而使用生僻倒装。

### 4.3 引号表演

谨慎使用“能出图”“跑得快”“真正落地”“看得见”等短语引号。术语名、信号名、书名和原话引用可保留。

### 4.4 句中加粗

连续正文避免频繁句中加粗。重点可交给标题、排版层级、图表或少量提示框。

### 4.5 破折号与括号

破折号可用于解释和转折；连续多段都用会形成固定节拍。括号保留缩写、单位、术语和必要旁注，其余内容并入正文。

### 4.6 连接词堆积

“首先、其次、此外、与此同时、因此、综上”连续出现时，先检查句间逻辑是否已经清楚。清楚就删除；不清楚就补具体关系。

## 5. 分文体注意事项

### 5.1 说明与分析

保留概念边界、事实关系、证据来源和成立条件。语言可以变得顺畅，推理链不能被压缩成空泛结论。

### 5.2 教程与实用文本

优先保证动作明确、顺序可执行、结果可判断。删掉对操作没有帮助的铺垫，不删必要警告和前提。

### 5.3 叙事与个人表达

保持叙述视角、人物关系、时间顺序和声音一致。自然化不等于增加虚构细节，也不强行把克制表达改成热情口吻。

### 5.4 评论与说服性文本

保留立场依据和论证强弱。价值判断需要材料支撑，不能用情绪化词语代替论证。

### 5.5 简介与短文本

先满足长度和功能限制。标题、简介、按钮和提示语需要快速识别，不适合套用长文的铺垫与收束。

### 5.6 学术论文

详细参考见 [academic-paper-guide.md](academic-paper-guide.md)。核心要点：

- **语域**：从口语切换为学术书面语。删除"随着…发展""本文将从…展开"等空泛开场；用"指示"替代"告诉"、"移除"替代"取消"、"并不可靠"替代"也会出错"。删除"可/可以"商量语气。减少"其/该/本"代词过载。
- **姿态**：论文以作者身份正面陈述，删除辩护（"并非本文独创"）、纠正（"不在于A而在于B"）、服务（"希望有所帮助"）句式。说"是什么"和"为什么"。
- **术语**：核心名词首次出现即定义；全文命名一致；自创词首次出现括号定义或一句解释；内部术语不进摘要。
- **逻辑**：动机在前、方法在中、公式在后；图表引用在概念引出之后；包含关系不写成并列；段间补过渡和逻辑桥。
- **冗余**：缩写只展开一次；强前提已蕴含的推论不再重述；一段内同一主张出现 ≥2 次否定式保证必有一处冗余。

## 6. 交付前复读

完成后逐项检查：

- 去掉标题后，每段是否仍有具体信息；
- 是否连续三段使用相同开头、列举方式或结尾；
- 是否反复预设读者误解，再用对立句纠正；
- 是否为了自然加入虚假经历、语病或随意口语；
- 是否改变事实关系、成立条件、叙述视角或作者立场；
- 是否仍像提纲拼接；朗读时哪里会卡顿或显得刻意。
